# ACP agents for all study-material generation

Transcript cleanup, Notes, Flashcards, Quiz generation, course synthesis, chat, and Antigravity transcription use local agent processes. ChatGPT and OpenCode remain externally installed ACP agents. Antigravity uses Google's official `agy_acp_server` runtime, which Lectern downloads as a pinned, versioned pair with `localharness_external`, validates through ACP `initialize`, and activates atomically under Application Support. Its `oauth-personal` profile is isolated from the normal `agy` CLI; the agent owns authentication and credentials. Prompts, images, text, PDFs, and supported audio travel as native ACP content blocks. This keeps provider-specific protocol and authentication behind the Antigravity ACP boundary and avoids private Google endpoints or CLI print-mode wrappers. Consequences: Antigravity requires a roughly 315 MB managed download and a separate Google sign-in; account model configuration advertised by ACP is authoritative.
